## เดือนยังไม่รู้ (`cursor === null`) — **เปิดดูจริง ไม่ได้เดา**

ไม่มีทางไปถึงผ่าน mount order ปัจจุบัน (cursor effect กับ mounted effect ลงคอมมิตเดียวกัน) แต่ type ของ goo บอกว่าเป็นไปได้
⇒ **"ปลอดภัยเพราะกลไกอื่นบังเอิญกันไว้" ไม่ใช่ invariant** ⇒ handle ตรงๆ แล้ว**บังคับ render ออกมาดู** (mutation ชั่วคราว แล้วถอดออก):

```
["วันนี้", "เดือน—", "ปี (พ.ศ.)—"]  disabled=[true,true,true]  top=250 height=62
```
⇒ ขนาด/ตำแหน่งเท่ากับตอนรู้เดือนเป๊ะ ⇒ **cursor ลงมาแล้วแถบขยับไม่ได้เชิงโครงสร้าง** · ❌ ไม่มี "กรกฎาคม 2569" โผล่สภาพไหน

## adversary sign-off

ผมพยายามหักใบตัวเองด้วย 4 ทาง — 3 ทางหักได้จริงและแก้แล้ว:

1. **"แถบโผล่ทุกสภาพแล้ว"** → หักได้ **ยังไม่จริง** มี state ที่ 6 ที่ไม่โผล่ (ดูข้างล่าง) ⇒ แก้คำอ้างไม่ใช่แก้ตัวเลข
2. **"วัด tier-pending แล้ว"** → หักได้ ผม mock `/api/tier` ที่**ไม่มีใครเรียก** รอบแรกเลยได้ภาพแถบเต็มๆ และเกือบรายงานว่า "tier-pending มีแถบ" ⇒ ใส่ assert ว่า spinner อยู่บนจอจริงก่อนอ่านค่า
3. **"scrollIntoView ช่วยให้หาปีเจอ"** → หักได้ negative control บอกว่าแยกไม่ออกทั้ง 4 จอ ⇒ ลบ
4. **"ด่านใหม่จับได้"** → หักได้ มันไม่แดง มัน **crash** ⇒ guard แล้วพิสูจน์ซ้ำ

**ยังไม่ได้พิสูจน์ (ไม่ใช่ว่าครอบแล้ว):**
- 320 / 360 กว้าง — วัดที่ 393 อย่างเดียว (แถบไม่เปลี่ยนโครง แต่**ยังไม่ได้เปิดดู**)
- ตัวเลือก **เดือน** ข้ามปี (ธ.ค.→ม.ค.) วัดผ่านโค้ด `goTo` ที่ไม่ได้แตะ แต่**ไม่ได้กดจริงข้ามปี** — กดข้ามเดือนในปีเดียวกันแล้ว (ส.ค.→ม.ค. ผ่าน)
- แถบใน `data-cursor="unknown"` — เปิดดูด้วย mutation ชั่วคราว **ไม่ใช่ผ่านทางที่ผู้ใช้เดินมา** (ไปไม่ถึงจริง)
